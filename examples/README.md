# 示例 prompt（直接照抄就能用）

如果你装了斜杠命令，也可以用命令代替（见 `../commands/`，或跑 `/qiuzhi` 看总览）。

## 一句提醒

示例里的 `【】` 是占位符，替换成你自己的信息再发。信息不全也没关系，AI 会先问你缺的那一两项。
