# 模拟面试 · 可直接粘贴

## 一句话开始

```
模拟面试，岗位是【后端开发】，用我这份简历【D:/简历-后端版.pdf】，从【L1】开始，8 题。
```

## 不带简历（也能练）

```
模拟一场【嵌入式软件】岗位的技术面，我是应届本科，从 L0 到 L2 各来几题。
一次只问一题，我答完你再追问，最后给分和复盘。
```

## 做完了想复盘

```
把刚才这场面试的复盘表整理出来：每题我的原话关键句、错在哪、参考答法、五维分数，
再统计一下重复出现的 gap（同类错误出现两次以上的单独标出来）。
```

## 想问 HR 面

```
换个 HR 面：自我介绍、优缺点、为什么选这家、反问环节、期望薪资。按真实强度来，别客气。
```
