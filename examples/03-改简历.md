# 改简历 · 可直接粘贴

## 有 JD 的（效果最好）

```
帮我改简历，按这个 JD 对齐。
简历：【粘贴简历全文或给文件路径】
JD：【粘贴岗位描述全文】

要求：只改表达不改事实，逐条给「改前 → 改后 → 为什么」。一次改 5-8 条，别整篇重写。
改完告诉我还差什么。
```

## 没 JD 的

```
帮我改简历，目标是【央国企 / 后端开发 / 嵌入式】方向。
简历：【粘贴全文】

重点看：一页能不能放下、每条经历有没有数字、有没有写了"精通"但经不起追问的词。
```

## 专门查一个毛病

```
我这简历里的数字，你觉得哪些经不起三层追问？逐条列出来，我判断要不要删。
```
